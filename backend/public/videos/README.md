# 📹 Vidéos locales pour FlipLearn

Place tes fichiers **.mp4** téléchargés dans ce dossier avec **le nom exact** indiqué ci-dessous.
Le seed du serveur les détectera automatiquement au prochain boot et les associera au bon cours.

---

## 🛠️ Outil recommandé : `yt-dlp`

```bash
# Windows (via pip ou scoop)
pip install yt-dlp

# Télécharger une vidéo YouTube en mp4
yt-dlp -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]/mp4" -o "nom-du-fichier.mp4" "URL_YOUTUBE"
```

Place ensuite le fichier dans ce dossier avec le **nom exact** de la colonne "Fichier attendu".

## 🚀 Workflow complet

1. **Télécharge** les vidéos que tu veux (pas besoin de toutes les avoir, commence par quelques-unes) avec `yt-dlp`.
2. **Renomme-les** avec exactement le nom de la colonne "Fichier attendu".
3. **Place-les** dans ce dossier (`backend/public/videos/`).
4. **Redémarre** le serveur (ou attends le prochain boot).
5. Le seed scanne ce dossier, détecte les fichiers présents et remplace automatiquement les URLs mp4 samples par tes vidéos locales.

Les vidéos manquantes continueront d'afficher les samples Google Cloud (Big Buck Bunny, etc.) — comme ça l'app reste utilisable même avec 0 fichier local.

---

## 📦 Exemple concret de commande `yt-dlp`

```bash
# Se placer dans le dossier
cd backend/public/videos

# Télécharger une vidéo sur Scrum
yt-dlp -f "bestvideo[height<=720][ext=mp4]+bestaudio[ext=m4a]/mp4" \
  -o "manage-l3-pm-01.mp4" \
  "https://www.youtube.com/watch?v=XXXXX"
```

---

## 🌐 URL finale servie par l'app

Une fois placées, les vidéos sont servies à cette URL par Express :

- Fichier : `backend/public/videos/isil-l1-algo-01.mp4`
- URL : `http://localhost:5000/videos/isil-l1-algo-01.mp4`

Le seed stocke exactement cette URL en DB pour que le lecteur vidéo la trouve.

---

## ⚠️ Pour le déploiement Render (prod)

Les fichiers dans ce dossier sont dans `.gitignore` par défaut (voir `.gitignore` du projet). Options :

- **Tester en local uniquement** : rien à faire, les fichiers locaux marchent.
- **Déployer sur Render avec vidéos** : soit commit les vidéos (`git add -f backend/public/videos/*.mp4` — attention taille GitHub), soit upload sur Cloudinary et remplace les URLs via l'UI prof.

Si tu ne mets rien dans ce dossier, ton site reste fonctionnel avec les samples Google Cloud.
